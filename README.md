# Student Budget Tracker OOP
A Java Swing desktop application that helps students manage their allowance, income, expenses, and remaining balance.

## Features

- **Dashboard** – Displays the student's budget summary.
- **Add Income** – Records money received, such as allowance or part-time work.
- **Add Expense** – Records spending on food, transportation, school supplies, and other needs.
- **Edit Transaction** – Updates a selected income or expense.
- **Delete Transaction** – Removes a selected transaction.
- **Budget Categories** – Organizes transactions by category.
- **Data Saving** – Saves transaction records locally using a CSV file.

## Technologies Used

- Java
- Java Swing (Graphical User Interface) = I used Java Swing because it allows me to create a desktop application with buttons, tables, text fields, and other  graphical components using Java.

- Object-Oriented Programming (OOP)
- CSV file storage = CSV stands for Comma-Separated Values. It is a simple text-file format used to save information in rows.This helps the application reload saved transactions when it starts again.Also it is similar to a simple spreadsheet, but the information is stored in a text file instead of a database like MySQL.

## How to Run

1. Download or clone this repository.
2. Install a compatible Java Development Kit (JDK).
3. Open the project folder in VS Code.
4. Compile the Java files:

   ```bash
   javac *.java
   ```

5. Run the application:

   ```bash
   java Main
   ```

## Application Output

The application opens a desktop window displaying the budget dashboard, transaction table, and controls for adding, editing, and deleting transactions.
